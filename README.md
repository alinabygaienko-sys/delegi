# Delegi

Next.js rebuild of the site for Delegi, an AI automation studio that builds lead generation, outreach and voice follow up systems for small businesses.

The first version is a single HTML page in [ai](https://github.com/alinabygaienko-sys/ai). This repo moves it to a component based stack with 3D and scroll motion.

## Stack

* Next.js 16 and React
* Tailwind CSS 4 and shadcn/ui
* Three.js for the 3D hero
* GSAP and Framer Motion for scroll and reveal animation

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Status

Work in progress. Project setup and dependencies are in place; page sections are being moved over from the HTML version.
